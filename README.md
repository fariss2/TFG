# UV-Dermis: Plataforma de Prevención del Melanoma
![Portada app](https://github.com/fariss2/TFG/blob/main/img/posible_portada1.png)
Esta web ofrece información educativa sobre el cáncer de piel, alertas personalizadas basadas en factores ambientales (radiación UV, temperatura máxima y altitud) y acceso a bases de datos meteorológicos para futuras actualizaciones.Enlace [aplicación](https://nfarla02.shinyapps.io/UV-Dermis/ "Ir a UV-Dermis")
