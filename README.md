# UV-Derma: Plataforma de Prevención del Melanoma
Esta web ofrece información educativa sobre el cáncer de piel, alertas personalizadas basadas en factores ambientales (radiación UV, temperatura máxima y altitud) y acceso a bases de datos meteorológicos para futuras actualizaciones.
