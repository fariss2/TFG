\section{Descripción de los datos.}
Para la elaboración del proyecto se ha reunido un conjunto de datos a partir de fuentes de datos oficiales y APIs públicas, con el fin de analizar factores ambientales relacionados con el riesgo de desarrollar \textit{melanoma} maligno de piel.
Tras el proceso de limpieza de resultados obtenidos de la respuesta de la API de la AEMET se consiguen los datos asociados a cada provincia. Mediante este atributo común se realiza una unión de datos correspondientes a las temperaturas y al índice de radiación ultravioleta para obtener un único dataframe consolidado para la visualización en mapas. Un \textit{datarame}  en \textit{R} es una estructura de datos bidimensional que se emplea para almacenar y visualizar datos en forma similar a una tabla \cite{gonzalez-vidalTabularColaTabulacionDatos2019}. Una vez realizado el proceso de unión, se almacena localmente este conjunto de datos en un archivo de formato \textit{.rds} mediante la función \textit{saveRDS()}, que comprime los datos que almacena ocupando menos espacio \cite{RParaPrincipiantes}. En el contexto de \textit{R} estos archivos permiten guardar objetos como dataframes manteniendo su estructura y tipos que tenían originalmente, evitando la pérdida de información. Para la recuperación de este archivo se usa la función \textit{readRDS()} y de esta manera se evita la pérdida de los registros de días pasados y se añaden los nuevos datos del día actual. 

Los datos empleados se clasifican en  tres categorías:

\begin{enumerate}
    \item \textbf{Datos meteorológicos}: se obtienen mediante la API pública de la Agencia Estatal de Meteorología (AEMET) \cite{AEMETOpenDataa}, empleando el paquete de \textit{R climaemet} \cite{R-climaemet}, y se actualizan diariamente con el lanzamiento de la aplicación web. Las variables recogidas son las siguientes:
    \begin{itemize}
        \item Índice de radiación ultravioleta (UV): representa la intensidad de la radiación UV solar que se predice que va a incidir sobre la superficie terrestre en cada provincia.
        \item Temperatura máxima y mínima diaria: valor máximo y mínimo registrado en grados Celsius por provincia.
    \end{itemize}

    \item \textbf{Datos geográficos}: mediante el paquete \textit{climaemet} \cite{R-climaemet}, se accede a metadatos de las estaciones meteorológicas oficiales que incluyen la altitud, entre otros registros. Esta altitud representa la elevación de la estación meteorológica sobre el nivel del mar y se obtiene una altitud media por el conjunto de estaciones meteorológicas que pertenecen a cada provincia.

    \item \textbf{Datos de las defunciones por \textit{melanoma} maligno de piel}: estos registros se extraen del Instituto Nacional de Estadística a través de su respectivo paquete de \textit{R} \cite{INE_R}, que conecta con su API. De esta manera, cuando se realiza la actualización anual de estos datos, se verá reflejada automáticamente. Al igual que los conjuntos de datos anteriores, se recogen por provincias.
\end{enumerate}

Toda esta información se consolida automáticamente en un solo conjunto de datos que sirve de soporte para el correcto funcionamiento de la aplicación web. Esta plataforma no registra ni almacena información personal, sino que en su lugar, actuará como recomendador donde el usuario elige su zona geográfica y fototipo de piel  y se le imprimirá una sugerencia personalizada según los parámetros escogidos.
Este sistema se plantea como una herramienta educativa y preventiva, con potencial para informar a la población sobre la exposición solar y sus efectos adversos en un contexto social donde la moda del bronceado está en su máximo auge.  

En el futuro, la recopilación continua y estructurada de estos datos climáticos abrirá camino a estudios estadísticos más integrados y precisos. El conjunto de datos creado puede servir como punto de partida para analizar el efecto combinado de factores ambientales en el desarrollo del \textit{melanoma} maligno de piel. Además, al incorporar variables individuales como el fototipo cutáneo, se podrá realizar un análisis más personalizado, contribuyendo a una comprensión más profunda del papel que juegan las condiciones ambientales en la aparición y evolución de esta patología.

 \subsubsection{Aplicación web}
 Una aplicación web consiste en un \textit{software} que se ejecuta en el navegador web. Hoy en día se emplean como solución práctica para acceder a funcionalidades complejas sin necesidad de instalar o configurar un \textit{software}. Esto la convierte en una opción más práctica y versátil que las aplicaciones de escritorio tradicionales. Entre sus principales ventajas se encuentran:
 \begin{itemize}
     \item \textbf{Accesibilidad}: Las aplicaciones web son accesibles desde todos los navegadores web y desde diferentes dispositivos personales con diferentes sistemas operativos y con conexión a internet, garantizando una experiencia homogénea para todos los usuarios y simplificando el desarrollo de esta.
     \item \textbf{Desarrollo eficiente}: presenta un desarrollo sencillo y rentable como solución ya que al presentar compatibilidad con todos los sistemas operativos no requiere un desarrollo complejo.
     \item \textbf{Simplicidad para el usuario}: los usuarios no necesitan descargar las aplicaciones web, lo que hace que sean fáciles de acceder a la vez que se prescinde de mantenimiento y no consume espacio local. Las aplicaciones web reciben actualizaciones de \textit{software} y seguridad de manera automática, lo que significa que siempre están actualizadas y presentan menor riesgo de sufrir brechas de seguridad \cite{QueEsAplicacion}.
     
 \end{itemize}
 
Uv-Dermis es la aplicación web desarrollada cuyo lenguaje de programación es \textit{R} en el \textit{framework shiny}, su objetivo principal es informar, concienciar y prevenir el desarrollo del \textit{melanoma} maligno de piel mediante el uso de datos ambientales y características personales del usuario. Dado al contenido del grado de Ingeniería de la Salud, esta se sitúa en la intersección entre la salud pública y desarrollo de tecnologías para la prevención y el cuidado de la salud pública.
Esta plataforma presenta varias pestañas con distinto contenido accesibles desde la barra de navegación o los botones de acceso rápido presentes en la página principal de esta. Las pestañas más destacables son:

\begin{itemize}
    \item  \textbf{Mapa de variables}: Este módulo permite la visualización de la variabilidad geográfica de las variables ambientales claves asociadas al riesgo de \textit{melanoma}: el índice UV diario, la temperatura máxima diaria y la altitud media por provincia. También muestra la tasa de incidencia del \textit{melanoma} en España según la última actualización de la INE. Esta pestaña está diseñada para que el usuario pueda explorar visualmente las diferencias existentes entre estos factores entre las provincias.
    
    \item \textbf{Calculadora de riesgo de \textit{melanoma}}: Se trata de una  herramienta inspirada en la calculadora de predicción del Instituto Australiano del Melanoma \cite{MelanomaRiskAssessment}. El objetivo de esta es realizar una estimación aproximada del riesgo existente con la información disponible, facilitando su prevención adaptada al contexto geográfico y biológico de cada usuario. En ningún momento sustituye la asistencia médica ya que el riesgo personal puede diferir de la estimación por factores externos.
    
    La estructura interna de esta herramienta se fundamenta en metodologías ampliamente validadas y usadas en medicina preventiva, como los modelos de predicción desarrollados en el estudio del corazón en Framingham \textit{(Framingham Risk Score)} para enfermedades cardiovasculares \cite{lloyd-jonesFraminghamRiskScore2004}, o el \textit{FINDRISC} para el diagnóstico de diabetes tipo 2 \cite{bernabe-ortizDiagnosticAccuracyFinnish2018}. Estos modelos convierten variables clínicas en categorías puntuadas según su riesgo aportado a su respectiva enfermedad analizada.
    
    En mi caso, la fórmula aplicada se basa en una suma ponderada de factores de riesgo categorizados según su influencia vista en los artículos científicos. Dado que no se dispone de estudios cuantitativos que asignen un peso estadístico exacto a cada factor, se ha optado por una aproximación heurística. Esta consiste en la asignación de puntos relativos a cada factor según su grado de asociación con el desarrollo del \textit{melanoma}, basándose en la evidencia cualitativa mencionada en los estudios parciales. La puntuación total acumulada permite ubicar al usuario en un intervalo de clasificación del riesgo relativo, lo cual puede orientar decisiones preventivas.
    \begin{itemize}
    \item \textbf{Radiación UV}: según Aceituno (2011) \cite{aceituno-maderaMelanomaAltitudeUVB2011}, la radiación UV es el principal factor de riesgo modificable para el desarrollo de \textit{melanoma} cutáneo, ya se encuentra clasificado por la OMS \cite{rehfuessGlobalSolarUV2002} según su efecto sobre la piel, por ello se le han asignado hasta un máximo de 6 puntos si este valor alcanza unos niveles elevados.
    
    \item \textbf{Temperaturas máximas}: el estudio que examinó difernetes causas de exposición a la radiación UV mencionado en el artículo de Bharath (2009) \cite{bharathImpactClimateChange2009}demostró el efecto indirecto de la temperatura, ya que a temperaturas elevadas menos capas de ropa llevamos y lo que aumenta la exposición a la radiación UV.
    
    \item \textbf{Altitud}: como se ha mencionado anteriormente en los conceptos teóricos, la altitud aumenta la radiación UV y por ello, a medida que aumenta la altitud aumenta la puntuación.
    
    \item \textbf{Fototipo de piel}: el estudio multivariante llevado a cabo en el estudio de Ballester (2012) \cite{ballesterMulticenterCaseControlStudy2012} demostró que aquellas personas con fototipos claros (I,II) tienen el doble de probabilidades de desarrollar un \textit{melanoma}.

    
    \item \textbf{Edad}: dado a que el sistema inmunitario se debilita con la edad, y siendo este sistema el que nos ayuda a combatir los cánceres, personas con avanzada edad tienen más probabilidades de padecer esta patología \cite{American_Cancer_Society}. 
    
    \item \textbf{Sexo}: según la Asociación Americana del Cáncer \cite{American_Cancer_Society}, los hombres tienen una tasa mayor de \textit{melanoma} que las mujeres, aunque esto varía según la edad. Antes de los 50 años, el riesgo es mayor para las mujeres; después de los 50, el riesgo es mayor para los hombres.
    
    \item \textbf{Presencia de lunares}: según 
    Ballester (2012) \cite{ballesterMulticenterCaseControlStudy2012} aquellas personas con lunares o nevos \footnote{Un nevo, también conocido como lunar, es una lesión benigna de la piel formada por un grupo de melanocitos.} melanocíticos presentaban un OR=3,1 lo que significa que tienen una probabilidad 3,5 veces mayor de desarrolar un \textit{melanoma}.
    
    \item \textbf{Antecedentes familiares}: el mismo estudio de Ballester (2012) \cite{ballesterMulticenterCaseControlStudy2012} demostró, que aquellas personas con familiares de primer grado con patologías en la piel presentaban un \textit{OR}\footnote{La \textit{OR} o \textit{Odds Ratio} (Razón de Posibilidades) es una medida estadística que cuantifica la relación entre dos variables. Estima la probabilidad de que un evento ocurra en un grupo en comparación con otro.}=3,1 lo que significa que tienen una probabilidad 3,5 veces mayor de desarrollar un \textit{melanoma} y por eso se le asocio una puntuación de dos puntos en caso afirmativo.

    \end{itemize}
    \item \textbf{Recomendador}: en esta pestaña se genera una recomendación según el fototipo de piel y las variables meteorológicas del usuario. Se clasificaron  los fototipos en tres clases según su riesgo, la temperatura según el tiempo y finalmente los índices de radiación UV se usan igual que están clasificados por la OMS, tabla \ref{tabla:clasificacion_variables}.
