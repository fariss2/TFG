\capitulo{2}{Objetivos}

Para comenzar con esta memoria se empezará definiendo los objetivos que se busca alcanzar con la realización de este trabajo. El principal propósito de este proyecto es informar y educar sobre el impacto de variables ambientales en el desarrollo de \textit{melanoma} de piel maligno; por otra parte, se alertará al usuario de la presencia de factores de riesgo en su provincia. 

\section*{Objetivos}

\begin{itemize}
    \item Desarrollar una aplicación web interactiva empleando \textit{Shiny} que visualiza la variabilidad geográfica de la mortalidad por melanoma de piel.

    \item Dotar al usuario de conocimientos sobre el impacto de estas variables ambientales en la salud humana. 

    \item Alertar  al usuario sobre la presencia de factores de riesgo en una zona geográfica determinada por el mismo junto a unas recomendaciones para protegerse del peligro.

    \item Hacer uso  de las fuentes de datos abiertas, INE y AEMET principalmente, para obtener los datos necesarios y realizarles un proceso de limpieza para aportarles una estructura adecuada para su procesamiento.

    \item Mediante solicitudes con la API adecuada aportar al sistema una actualización periódica de los datos empleados para las alertas personalizadas.

    \item Aportar una visualización de información relevante y estudios realizados por expertos sobre el efecto de estos factores meteorológicos.

    \item Aplicar conocimiento adquiridos en el grado para realizar un procesamiento de datos para aportarles una estructura adecuada para su fácil interpretación por el público. 

    \item Poder diseñar y desplegar la web para que sea accesible a todo el público. 

    \item Profundizar los conocimientos en \textit{R}, ciencia de datos y salud pública y de esta manera aplicar y mejorar los adquiridos en el grado.

    \item Familiarizarse con nuevas herramientas y enfoques informáticos, especialmente en el desarrollo de interfaces interactivas con \textit{Shiny}.

    \item Contribuir al ámbito de epidemiologías ambientales, aportando un nuevo recurso accesible para divulgar y prevenir nuevos diagnósticos de \textit{melanomas} de piel 

\end{itemize}
